# NextBiz Studio agency homepage

## Goal
Build one polished, responsive homepage that closely recreates both supplied agency references as a continuous page, branded as **NextBiz Studio** with the supplied NB logo.

## Page structure
1. Recreate the framed navigation and opening section from the first reference, including the call-time block, opening copy, two actions, and layered portrait composition.
2. Add the partner-logo strip and the “Who We Are” section with the portrait, four statistics, and contact action.
3. Continue with every section in the second page reference, in the same order and visual composition:
   - Services
   - Selected work
   - Industries
   - Client story
   - Team
   - Project call-to-action
   - Footer and newsletter field
4. Preserve the visible wording, example projects, people, statistics, and phone number, while replacing visible Ritovex brand references with NextBiz Studio.

## Visual fidelity
- Match the references’ warm white canvas, thin dividers, restrained black typography, small rounded labels, image corner treatments, handwritten annotations, spacing, and dense editorial rhythm.
- Build every distinctive button, card, statistic block, project tile, label, and control as a purpose-made component matching the references; do not fall back to generic UI-kit treatments.
- Use the uploaded NB artwork as the site logo and derive the favicon from it.
- Create cohesive supporting photography that closely matches the subjects and framing shown in the references, without copying third-party identities or logos.
- Keep the desktop composition faithful while adapting the same hierarchy cleanly for phones and tablets.

## Interaction
- Navigation, service links, project links, and calls to action will smoothly scroll to the corresponding homepage sections.
- Dropdown indicators and testimonial arrows will have clear interactive states without adding new pages.
- Add restrained entrance and hover motion, with reduced-motion support.

## Technical details
- Replace the current blank home screen with the complete page.
- Store the supplied logo through the project’s media flow and use semantic design tokens for the full visual system.
- Add page-specific title, description, social metadata, and accessible labels/alternative text.
- Verify the finished page at desktop and mobile sizes, checking visual alignment, image loading, navigation behavior, overflow, and the latest build/runtime signals.

## Scope note
This pass creates the full visual homepage and in-page navigation. It does not add form submission, newsletter delivery, external booking, or separate service/project pages.
